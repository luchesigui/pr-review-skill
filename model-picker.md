# Choose review providers and models

1. List installed providers with `python3 -I <SKILL_DIR>/scripts/model_catalog.py --providers`. Include any existing `agents.custom_commands` provider names as options. Show the options and ask which providers the user has access to and wants to use. For a model-only update, ask which roles to edit and offer to keep their current providers. Once the roles and providers are selected, proceed to catalog discovery. A provider already named in the request counts as selected.
2. Fetch the catalogs for the selected built-in CLI providers in one call using `python3 -I <SKILL_DIR>/scripts/model_catalog.py --catalog <provider> [<provider> ...]`. For `native`, use the current harness's selectable models when available. For a custom provider, use its configured model or ask for the model ID. Only look up selected providers.
3. Present the results grouped by provider, with numbered model choices for each and an option for the provider default. Use the current role settings as defaults when reconfiguring. For a first setup, let the user assign one provider/model pair to all roles and override individual roles, including `general_escalated` and `da_overflow`. Accept exact IDs if the user has one already. When discovery is unavailable, offer the current setting, provider default, or a manual ID. Ask about effort only if the user wants to customize it and the runner supports it.
4. Save the selected provider and model for each role using the exact CLI choice returned by the catalog, or an empty model string for provider default. In models mode, apply the requested fields with `scripts/models.py`. In setup mode, include the selections in the configuration saved at the end of setup.

The catalog uses the local Claude, Codex, Grok, and Antigravity (`agy`) CLIs where available. Claude and Grok fall back to their official model APIs with `ANTHROPIC_API_KEY` or `XAI_API_KEY`. Gemini uses the Gemini Developer API with `GOOGLE_API_KEY` or `GEMINI_API_KEY` when available. An API-key catalog reflects that key's access, which can differ from the CLI login. Codex can report a bundled catalog. Show the source and treat the listings as choices, without claiming verified inference access.
